# Friender – Social Media Platform Clone

Friender is a full-stack social media web application developed as part of the Lenovo Romania Summer Internship Program. It is designed to replicate the core features of a social media platform, allowing users to register, authenticate, create posts, interact with other users, and manage their profile – all within a secure and scalable environment.

## 🚀 Features

- 🔐 **User Authentication** – Secure login/register system using JWT.
- 📝 **Post Creation** – Users can create, edit, and delete their own posts.
- 💬 **Comment & Like System** – Engage with others through likes and comments.
- 🧑 **User Profiles** – View and edit personal profile information.
- 🕵️ **Admin Panel** – For moderation and user management (optional).
- 🌐 **Responsive Design** – Mobile-friendly UI using Angular.
- 📡 **REST API** – Backend developed with Express.js and tested via Postman.
- 💾 **MongoDB** – NoSQL database for user and post management.

## 🛠️ Technologies Used

### Frontend
- **Angular** – TypeScript-based frontend framework.
- **HTML/CSS & Angular Material** – UI components and styling.

### Backend
- **Node.js & Express.js** – Server-side logic and REST API.
- **JWT (JSON Web Tokens)** – For secure authentication.
- **Mongoose** – ODM for MongoDB.

### Tools & DevOps
- **MongoDB Atlas** – Cloud-hosted database.
- **Postman** – API testing and documentation.
- **Git & GitHub** – Version control and collaboration.
